## ⚙️ Template Workflow Notes

### Hotkey Automation

The "Hotkey Trigger" column is for your personal use. If you install the **Templater** plugin, you can set up a command for each template (e.g., typing `/t-atom` to insert the Atomic Note template).

### Quick Edit

To quickly edit a template: hold `Ctrl` or `Cmd` and click the link in the table above. It will open the template note for immediate editing.

### Template Maintenance

*   *When a new template is created, ensure it is added to the relevant table above.*
*   *Check periodically that the links in the "Links To" column are still relevant.*
