# 💡 OS Glossary

- Ruta de acceso absoluta: Corresponde a una ruta que comienza en el directorio principal.
- Alias: Es un sobrenombre para los comandos comunes.
- Marca append: Es una forma de agregar datos a un archivo sin borrar los existentes.
- Bash: Es el lenguaje que se usa para interactuar con la Shell.
- CLI: Significa “intérprete de línea de comandos”.
- Línea de comandos: Es un programa de interfaz de texto para computadoras que ingresa comandos de texto y los traduce al sistema operativo.
- Caracteres de escape: Es un concepto que significa que el siguiente carácter después del acento grave debe tratarse literalmente.
- .exe: Es una extensión de archivo de Windows para archivos ejecutables.
- Grupos: Corresponden a una colección de usuarios.
- GUI: Significa “interfaz gráfica de usuario”.
- Archivos ocultos: Son un conjunto de archivos que no son visibles para evitar alteraciones o simplemente porque no quieres que alguien los vea.
- Tecla de acceso rápido: Es una combinación de teclas para realizar una tarea específica.
- Flujos de E/S: Son flujos que controlan los datos que entran y salen de un programa.
- Parámetro: Es un valor asociado con un comando.
- Directorio principal y directorios secundarios: Un directorio principal es un directorio que aloja todos los directorios secundarios.
- Rutas de acceso: Se generan cuando un directorio principal se ramifica y almacena otros directorios y archivos.
- Prompt: Es un indicador que muestra en qué directorio te encuentras actualmente.
- Expresión regular: Corresponde a un lenguaje de coincidencia de patrones que describe palabras, frases o patrones más complicados. Las expresiones regulares se usan para ayudar a realizar una selección avanzada basada en patrones.
- Ruta de acceso relativa: Es una ruta de acceso del directorio actual.
- Directorio raíz: Es un directorio principal para todos los demás directorios de un sistema de archivos.
- Shell: Es un intérprete de línea de comandos para Linux.
- Error estándar (stderr): Es un flujo de datos que redirecciona el resultado de los mensajes de error en un flujo de salida diferente. Funciona en Linux y Windows.
- Entrada estándar (stdin): Es un flujo de datos en el que la entrada que se ingresa a través del teclado va al flujo de entrada estándar del proceso con el que se está interactuando. Funciona en Linux y Windows.
- Salida estándar (stdout): Corresponde a un flujo de datos que, cuando un proceso crea un resultado, agrega datos a la salida estándar, que sale del proceso. Funciona en Linux y Windows.
- Stdin, stdout y stderr: Son los tres flujos de datos que se crean cuando se inicia un comando de Linux.
- Subdirectorios: Corresponden a directorios en el nivel inferior o en un nivel más bajo en la jerarquía de directorios.
- Completado de línea de comandos: Es una forma de autocompletar comandos o nombres y directorios de archivos.
- Comodín: Es un carácter que se usa para seleccionar archivos según un patrón determinado.
